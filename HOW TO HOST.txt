MIND//VESSEL — play with friends
================================

HOST
----
1. Double-click  MIND VESSEL Host  (in this folder).
   First time: right-click → Open → Open.

2. A lobby page opens in your browser.

3. Click  Play here  to join on this Mac.

4. For friends ANYWHERE (internet):
   Wait a few seconds for “worldwide invite”.
   Click  Copy worldwide invite  and send that link.
   They open it in a browser — done.
   (First run may download a small helper for the tunnel.)

5. Optional — friends on the SAME Wi‑Fi only:
   Use  Copy Wi‑Fi invite  instead.

6. Quit the Host app from the Dock to stop.


KEEP THE HOST RUNNING
---------------------
Your Mac must stay awake with the Host app open.
When you quit, the worldwide link dies.


NEED NODE.JS ONCE
-----------------
https://nodejs.org  → LTS → install → open the Host app again.
